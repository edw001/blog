# 상수계수를 갖는 고계 제차미분방정식
### 풀이법
2계 때와 동일하게 $(D^n+a_{n-1}D^{n-1}+\cdots+a_1D+a_0)y=0$에 대해 특성방정식 $\lambda^n+a_{n-1}\lambda^{n-1}+\cdots+a_1\lambda+a_0=0$을 세우고 일반해를 구한다.
### 특성방정식 해에 따른 해의 기저
1. 서로 다른 실근 $\lambda_1,\lambda_2,\cdots,\lambda_n$의 경우
	- 해의 기저 : $e^{\lambda_1}x,e^{\lambda_2}x,\cdots,e^{\lambda_n}x$
2. 실근 $\lambda$가 $m$번 중복된 경우 (중근)
	- 해의 기저 : $e^{\lambda x},xe^{\lambda x},\cdots,x^{m-1}e^{\lambda x}$
3. 복소근 $\lambda = \alpha\pm\beta i$ 의 경우
	- 해의 기저 : $e^{\alpha x}\cos(\beta x),e^{\alpha x}\sin(\beta x)$

# 오일러-코시 미분방정식
### 풀이법
2계 때와 동일하게 $a_nx^ny^{(n)}+a_{n-1}x^{n-1}y^{(n-1)}+\cdots+a_{1}xy^{(1)}+a_0y=0$에 대해 특성방정식 $a_nm(m-1)\cdots(m-n+1)+\cdots+a_1m+a_0=0$을 세우고 일반해를 구한다.
### 특성방정식의 해에 따른 해의 기저
1. 서로 다른 실근 $m_1,m_2,\cdots,m_n$의 경우
	- 해의 기저 : $x^{m_1},x^{m_2},\cdots,x^{m_n}$
2. 실근 $\lambda$가 $m$번 중복된 경우 (중근)
	- 해의 기저 : $x^{\lambda},x^{\lambda}\ln|x|,\cdots,x^{\lambda}(\ln|x|)^{m-1}$
3. 복소근 $m = \alpha\pm\beta i$ 의 경우
	- 해의 기저 : $x^{\alpha}\cos(\beta\ln|x|),x^{\alpha}\sin(\beta\ln|x|)$
